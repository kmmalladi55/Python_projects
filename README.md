AI/ML Projects Portfolio

This repository showcases a collection of AI and Machine Learning projects completed during my Postgraduate Program in Artificial Intelligence & Machine Learning (AIML).
Each project demonstrates a full workflow — from data exploration and feature engineering to model building, evaluation, and business insights — using real-world datasets and Python’s data science ecosystem.

Languages & Tools Used:

Programming: Python

Libraries: NumPy, Pandas, Seaborn, Matplotlib, Scikit-learn, NLTK, TensorFlow, Keras, XGBoost

Environment: Jupyter Notebook
